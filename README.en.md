Payment Method Discount Plugin
===============================

[Русская версия](README.md)

The plugin allows you to set a discount on an order depending on the payment method selected by the customer.

The plugin adds another type to the discounts section: "By payment method". In the settings, you can specify which payment methods configured in the store should receive a discount and what is the discount amount as a percentage of the order total.

The plugin is fully analogous to standard discount types, and all standard discount configuration tools affect its behavior: summing, assignment by products, etc. It is not possible to configure individual plugin behavior, for example, to always offer a discount even if the store is configured to select the maximum discount.
